# Eniac x Magist: Brazilian E-Commerce Analysis

## 📌 About the Project

This project is a fictional business case about **Eniac**, a European technology company considering an expansion into the Brazilian market.

Eniac is considering a three-year partnership with **Magist**, a Brazilian e-commerce service provider. Our task is to analyze Magist's data and determine whether Magist would be a suitable partner for Eniac.

## 🎯 Business Question

**Should Eniac sign a three-year partnership with Magist?**

To answer this question, we analyze the available data and look at areas such as:

- Orders and customers
- Products and product categories
- Sales and payments
- Delivery performance
- Customer reviews
- Brazilian e-commerce market

## 🗃️ Data

The project uses a fictional dataset based on Magist's e-commerce database.

The database contains information about:

- Products
- Sellers
- Customers
- Orders
- Order items
- Payments
- Reviews
- Geographical data
